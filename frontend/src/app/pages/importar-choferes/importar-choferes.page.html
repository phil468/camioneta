Importar Choferes Instrucciones

Suba un archivo Excel (.xlsx, .xls) o CSV con las siguientes columnas:

  • CLIENTE: Nombre del cliente
  • CHOFER: Nombre completo del chofer
  • DNI: DNI del chofer (8 dígitos)
  • PLACA: Número de placa del vehículo
Si el cliente o la placa no existen, se crearán automáticamente. Si el chofer ya existe (mismo DNI), se actualizará. Seleccionar Archivo
