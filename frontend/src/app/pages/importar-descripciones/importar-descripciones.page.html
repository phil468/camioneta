Importar Descripciones de Jabas Instrucciones

Suba un archivo Excel (.xlsx, .xls) o CSV con las siguientes columnas:

  • CLIENTE: Nombre del cliente propietario
  • CODIGO: Código único de la jaba
  • DESCRIPCION DE JABAS: Descripción detallada
Si el cliente no existe, se creará automáticamente. Si la descripción ya existe (mismo código), se actualizará. Seleccionar Archivo
